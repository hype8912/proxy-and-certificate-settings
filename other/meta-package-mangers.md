# Meta-package Managers

Meta package managers are package managers that sit on top as a layer to interact with a collection of standard package managers to create a unified interface.

| Name | Supported Managers |
| :---: | --- |
| [Lure](https://github.com/lure-sh/lure) | apk<br>apt<br>dnf<br>pacman<br>yum<br>zypper |
| [mpm](https://github.com/kdeldycke/meta-package-manager) | See [managers](https://github.com/kdeldycke/meta-package-manager?tab=readme-ov-file#metadata-and-operations) |
| [ni](https://github.com/antfu-collective/ni) | bun<br>deno<br>npm<br>pnpm<br>yarn |
| [pacaptr](https://github.com/rami3l/pacaptr) | See [managers](https://github.com/rami3l/pacaptr?tab=readme-ov-file#supported-package-managers) |
| [pacdef](https://github.com/steven-omaha/pacdef) | apt<br>cargo<br>dnf<br>flatpak<br>pacman<br>pip<br>rustup<br>xbps |
| [pkgtop](https://github.com/orhun/pkgtop) | apt<br>dnf<br>guix<br>nix<br>pacman<br>portage<br>xbps<br>zypp |
| [Switch Package Manager](https://github.com/deinsoftware/swpm) | bun<br>npm<br>pnpm<br>volta<br>yarn |
| [UniGetUI (WingetUI)](https://github.com/marticliment/UniGetUI) | cargo<br>choco<br>npm<br>nuget<br>pip<br>powershell 5 & 7<br>scoop<br>vcpkg<br>winget |
| [UPM](https://github.com/replit/upm) | python-uv<br>python-pip<br>python-poetry<br>node-npm<br>node-pnpm<br>node-yarn<br>elisp-cask<br>dart-pub.dev<br>ruby-bundler<br>rlang<br>java<br>rust<br>dotnet<br>php |
